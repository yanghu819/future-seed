# Sudoku9 Unique Manifests

This directory holds the tracked manifests for the canonical 9x9 unique-solution Sudoku benchmark.

## Files

- `val_smoke.jsonl`
- `test_smoke.jsonl`
- `manifest_summary_smoke.json`

These smoke files are tiny deterministic examples used for self-test and dry-run checks.

## Manifest format

Each JSONL row has:

- `split`: `val` or `test`
- `clue_count`: number of givens in the puzzle
- `item_id`: deterministic item identifier
- `puzzle`: 81-character board with `0` for blanks
- `solution`: 81-character solved board

All rows are generated by the local uniqueness-checked generator in `scripts/sudoku9_unique.py`.

## Build full manifests

```bash
cd posttrain_rwkv7
python3 scripts/build_sudoku9_unique_manifests.py \
  --out_dir assets/sudoku9_unique \
  --clues 40,36,32,28,24 \
  --val_per_clue 1000 \
  --test_per_clue 2000 \
  --seed 20260312
```

This will write:

- `val_seed20260312.jsonl`
- `test_seed20260312.jsonl`
- `manifest_summary_seed20260312.json`

## Role in the repo

- `scripts/train_sudoku9_unique_sft.py` is the canonical 9x9 in-place trainer.
- `scripts/run_sudoku9_unique_maintrack.py` is the fixed main-track orchestrator.
- The older `scripts/train_sudoku_sft.py` remains an archive probe and is not the canonical Sudoku benchmark.
